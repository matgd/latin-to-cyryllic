# LДтiП <-> СуЯilliС (Visual Homoglyph Mapper)

A premium "Faux Cyrillic" converter that maps Latin characters to their visual
Cyrillic look-alikes (Homoglyphs).

## Features

- **Instant Conversion**: Real-time mapping as you type.
- **Rus Factor (CS Rank)**: A meter that calculates how "Slavic" your text
  looks, rating you from **Silver I** to **The Global Elite**.
- **Dark/Light Mode**: Automatically detects system preference or can be toggled
  manually.
- **Copy to Clipboard**: Easy one-click copy for both input and output.
- **Extensible Map**: Easily modifiable character mapping in `script.js`.
- **Mobile Responsive**: Works on mobile devices.

## Tech Stack

- HTML5
- CSS3 (Variables, Glassmorphism, Animations)
- Vanilla JavaScript

## Usage

Simply type in the Latin Input box and watch the transformation.
